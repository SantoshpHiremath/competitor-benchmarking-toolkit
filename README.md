# Competitor Benchmarking Toolkit

A tested Python pipeline for competitor and market benchmarking: it collects, structures, validates, and analyzes financial, product, and market-share information from multiple sources, and supports benchmarking, trend analysis, and ad-hoc research.

## What it does

A pipeline that generates multi-source competitor data (financial reports, product announcements, market-share estimates), reconciles the parts that disagree with each other, benchmarks revenue growth and margins across competitors, identifies segment/region leaders, and writes everything into a formatted, multi-sheet Excel report with every figure traceable back to its source.

I built it to work through the kind of messy, multi-source data reconciliation that market and competitive intelligence involves. Real competitor data comes from annual reports, analyst estimates, and press releases that don't always agree, and sometimes simply don't disclose a figure at all. A dashboard or a slide built on that data is only trustworthy if the reconciliation underneath it is done carefully and transparently.

## Data

All company names, financial figures, and market-share numbers are fictional, generated by `src/data_sources.py`. The project demonstrates the analytical and data-handling method rather than real market intelligence, and the pipeline is built so real sources can replace the generated data.

- The currency conversion rate (0.92 USD→EUR) is a fixed illustrative constant.
- Market-share estimates are randomly generated per segment/region and don't necessarily sum to a clean 100%, as real analyst estimates from different sources rarely do either.

## Components

- **`src/data_sources.py`**: generates synthetic financial records, product announcements, and market-share estimates across 4 fictional competitors, 3 segments, and 3 regions. It injects two realistic problems: a competitor reported at materially different revenue figures by two different sources (Annual Report vs. Analyst Estimate), and a competitor that didn't disclose its EBIT margin for a given year (a common gap in competitive intelligence, treated as missing rather than zero).
- **`src/reconcile.py`**: normalizes currency (USD to EUR at a fixed, documented rate), flags conflicting reports above a materiality threshold, flags missing required fields, and resolves conflicts using an explicit, documented tie-breaking rule (prefer the Annual Report over an Analyst Estimate or Press Release) rather than an arbitrary "first row wins."
- **`src/benchmarking.py`**: ranks competitors by year-over-year revenue growth, benchmarks EBIT margin against the peer average (excluding undisclosed margins from the average, not just the individual result), and identifies the market-share leader in each segment/region combination.
- **`src/report.py`**: writes a formatted `.xlsx` workbook (via `openpyxl`) with six sheets: Summary, Revenue Growth, Margin Benchmark, Segment Leaders, Product Announcements, and Data Quality Flags. Every number stays linked to its originating source.
- **`run_pipeline.py`**: runs the full flow end to end and prints a report to the console (see sample output below, copied from an actual run).
- **`power_query_equivalent.m`**: a hand-written Power Query M expression mirroring the same currency-normalization and conflict-flagging logic from `src/reconcile.py`, showing how the logic maps to M. It has not been run inside Power Query/Excel; the Python implementation is the tested reference; the same approach is used in my `powerquery-sap-reporting` project.

## Tests

32 automated tests (`tests/`), all passing, covering: data generation (reproducibility, injected conflicts and missing values land where expected), currency normalization, conflict detection (flags material spreads, ignores immaterial ones), missing-field detection, the conflict-resolution tie-breaking rule (including the fallback case when the preferred source isn't present), and the Excel report itself (the file is created, contains the expected sheets, and the data in each sheet matches the input).

```bash
python3 -m pytest -v      # 32 tests, all passing
python3 run_pipeline.py   # runs the full pipeline, writes output/competitor_benchmark_report.xlsx
```

## Project structure

```
src/
  data_sources.py   -- synthetic multi-source competitor data
  reconcile.py      -- currency normalization, conflict/missing-field flags, resolution
  benchmarking.py   -- growth ranking, margin benchmark, segment leaders
  report.py         -- Excel report writer
tests/              -- 32 tests
run_pipeline.py     -- end-to-end run
power_query_equivalent.m
output/competitor_benchmark_report.xlsx
```

## Possible extensions

- Replace the generated data with real annual-report and analyst-estimate sources.
- Use a dated exchange-rate table instead of the fixed 0.92 constant.
- Add a dashboard layer (Power BI or Tableau) on top of the Excel output.
