# Competitor Benchmarking Toolkit

A real, tested Python pipeline for competitor and market benchmarking — built specifically to close the "collect, structure, validate, and analyze market, competitor, financial, product, project, and industry information from internal and external sources" and "conduct benchmarking, trend analysis, and ad-hoc research" tasks named in Innomotics' "Working Student Market & Competitive Intelligence" posting.

## What this is

A pipeline that generates realistic, multi-source competitor data (financial reports, product announcements, market-share estimates), reconciles the parts that genuinely disagree with each other, benchmarks revenue growth and margins across competitors, identifies segment/region leaders, and writes everything into a real, formatted, multi-sheet Excel report with every figure traceable back to its source.

**All company names, financial figures, and market-share numbers are entirely fictional**, generated by `src/data_sources.py`. This is not real market research and does not describe any real company, including Innomotics or its actual competitors. The point of this project is to demonstrate the analytical and data-handling method, not to present real market intelligence.

## Why this exists

This project was built to demonstrate real, hands-on experience with the specific kind of messy, multi-source data reconciliation a market & competitive intelligence analyst actually deals with — not just clean, single-source analysis. Real competitor data comes from annual reports, analyst estimates, and press releases that don't always agree, and sometimes simply don't disclose a figure at all. A dashboard or a slide built on top of that data is only trustworthy if the reconciliation underneath it is done carefully and transparently.

## What it actually does

- **`src/data_sources.py`** — generates synthetic financial records, product announcements, and market-share estimates across 4 fictional competitors, 3 segments, and 3 regions. Deliberately injects two realistic problems: a competitor reported at materially different revenue figures by two different sources (Annual Report vs. Analyst Estimate), and a competitor that didn't disclose its EBIT margin for a given year (a real, common gap in competitive intelligence, not something to silently treat as zero).
- **`src/reconcile.py`** — normalizes currency (USD to EUR at a fixed, documented rate), flags conflicting reports above a materiality threshold, flags missing required fields, and resolves conflicts using an explicit, documented tie-breaking rule (prefer the Annual Report over an Analyst Estimate or Press Release) rather than an arbitrary "first row wins."
- **`src/benchmarking.py`** — ranks competitors by year-over-year revenue growth, benchmarks EBIT margin against the peer average (correctly excluding undisclosed margins from the average, not just the individual result), and identifies the market-share leader in each segment/region combination.
- **`src/report.py`** — writes a real, formatted `.xlsx` workbook (via `openpyxl`) with six sheets: Summary, Revenue Growth, Margin Benchmark, Segment Leaders, Product Announcements, and Data Quality Flags — every number stays linked to its originating source.
- **`run_pipeline.py`** — runs the full flow end to end and prints a real report to the console (see sample output below, copied from an actual run).

## Verification

32 automated tests (`tests/`), all passing, covering: data generation (reproducibility, injected conflicts and missing values land where expected), currency normalization, conflict detection (correctly flags material spreads, correctly ignores immaterial ones), missing-field detection, the conflict-resolution tie-breaking rule (including the fallback case when the preferred source isn't present), and the Excel report itself (real file is created, contains the expected sheets, and the data in each sheet matches the input — not just that the function runs without crashing).

```bash
python3 -m pytest -v      # 32 tests, all passing
python3 run_pipeline.py   # runs the full pipeline, writes output/competitor_benchmark_report.xlsx
```

## Honest disclosure — Power Query

`power_query_equivalent.m` is a hand-written Power Query M expression mirroring the same tested currency-normalization and conflict-flagging logic from `src/reconcile.py`. **It has not been executed inside a real Power Query or Excel environment** — this build sandbox has no licensed Excel or Power BI Desktop available. It should be read as evidence of understanding how the same logic maps to M, not as independently-verified hands-on Power Query experience. This is the same honest framing used for the Power Query file in this portfolio's `powerquery-sap-reporting` project.

## Honest limitations

- All data is synthetic — no real competitor, financial, or market data is used or implied.
- The currency conversion rate (0.92 USD→EUR) is a fixed illustrative constant, not a live or historically accurate exchange rate.
- Market-share estimates are randomly generated per segment/region and don't necessarily sum to a clean 100% — intentional, since real analyst estimates from different sources rarely do either, but this means they should not be read as a real, reconciled market-share model.
